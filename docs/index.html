How It Works

graph LR A[Customer Input] -->|Raw Text| B(AI Service) B -->|JSON Intent| C{Orchestrator} C -->|Matching| D[(Database Catalog)] D -->|Product Data| E(Rules Engine) C -->|Context| E E -->|Price & Logic| F[Final Quote] F -->|Audit| G[(Audit Log)] style B fill:#e0e7ff,stroke:#4338ca,stroke-width:2px style E fill:#dcfce7,stroke:#15803d,stroke-width:2px style F fill:#fef3c7,stroke:#b45309,stroke-width:2px
1

Intent Extraction

Gemini Pro analyzes text to extract quantities, units, and material hints. It never guesses prices.

2

Match & Calculate

We map intent to real Inventory Items. The Rules Engine applies bulk discounts, unit conversions, and taxes deterministically.

3

Validate & Audit

Every step is recorded. If confidence is low or rules are violated, the quote is flagged for human review.

API Endpoints

POST /quotes/generate

Generates a quote from natural language.

// Request Body
{
  "requestText": "I need 40m2 of oak flooring.",
  "customerName": "Jane Doe",
  "companyId": "uuid..." // Or inferred from Token
}

// Response
{
  "id": "quote_123",
  "totalAmount": "1200.00",
  "isValid": true,
  "lines": [...]
}
GET /admin/logs

Retrieves the audit trail (Anti-Hallucination logs).

// Response
[
  {
    "action": "QUOTE_GENERATED",
    "details": {
      "prompt": "...",
      "aiConfidence": 0.95,
      "rulesApplied": ["BULK_DISCOUNT"]
    },
    "timestamp": "2026-01-30T12:00:00Z"
  }
]
